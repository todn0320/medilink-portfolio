# 실험 결과 (PoC 중간발표 단계)

이 폴더의 결과물은 **중간발표용 PoC 단계** 실험 결과입니다.

전체 5,000종 데이터로 넘어가기 전에, 22종 소규모 샘플로 데이터 증강 전략을 먼저 비교 검증한 것입니다.

<br>

## 실험 목적

ResNet 기반 알약 분류 모델에 어떤 증강 전략이 효과적인지 미리 검증하고,
본 학습(YOLOv8, 전체 5,000종)에 적용할 전략을 결정하기 위한 탐색 실험입니다.

<br>

## 실험 구성

| 파일명 prefix | 증강 방식 | Accuracy |
|---|---|---|
| `baseline_*` | 증강 없음 | 1.00 (소규모 과적합) |
| `pc1_light_aug_*` | 약한 회전 + 밝기 변화 | 1.00 |
| `pc2_color_aug_*` | 색상 / 명도 변화 | 0.93 |
| `pc3_geometry_aug_*` | 원근 / 아핀 변환 | 0.85 |
| `pc4_noise_aug_*` | 노이즈 추가 | 0.94 |
| `pc5_rotation_aug_*` | 회전 + 플립 | 0.93 |

<br>

## 결론

알약은 외형과 각인이 핵심 특징이라, 형태를 크게 바꾸는 Geometry 증강은 오히려 성능을 떨어뜨렸습니다.
실제 촬영 환경(카메라 노이즈, 조명 변화)을 모사한 **PC4 Noise 증강**을 최적 전략으로 선택했습니다.

본 학습은 이후 Azure H100 클러스터에서 YOLOv8 모델, 전체 5,000종 데이터셋으로 진행했습니다.
