# 07. 회고 & 트러블슈팅

## 주요 트러블슈팅

### 1. Azure VM IP 차단 문제
**상황**: Korea Central 리전 VM에서 AI Hub 데이터 다운로드 시 해외 IP 차단 발생  
**원인**: 물리적 위치는 한국이지만 네트워크상 `Country: US / Microsoft Corporation`으로 인식됨  
**해결**: 학원 노트북을 프록시 서버로 활용 (`proxychains4` + SSH 터널링), 이후 일부 VM을 East US 2 리전으로 스냅샷 이전  

### 2. 대용량 파일 처리 (3.4TB)
**상황**: Blob Storage 직접 마운트(blobfuse2) 방식으로 3.4TB 이미지 수신 시 연결 불안정  
**해결**: VM에 10TB Managed Disk를 직접 마운트하여 로컬 작업 후, 완료된 파일만 Blob Storage에 백업하는 2단계 방식으로 전환  

### 3. 병용금기 데이터 41만건 처리
**상황**: 병용금기 JSON 파일이 412,500건으로 단일 Parquet 변환 시 메모리 이슈  
**해결**: 30,000건씩 분할하여 복수의 Parquet 파일로 저장 후 합산 처리  

### 4. 의약품 허가정보 XML 파싱
**상황**: 허가정보 데이터에 XML이 포함된 컬럼(`EE_DOC_DATA` 등)이 존재하여 단순 CSV 처리 불가  
**해결**: XML → clean text 파싱 후 4가지 컬럼(효능/용법/주의사항/금기)으로 분리, `NB_DOC_CODE` 컬럼 제거  

### 5. 낱알식별 이미지 URL 파싱 오류
**상황**: `ITEM_IMAGE` 컬럼에 URL 뒤로 다른 JSON 내용이 혼입되는 파싱 오류  
**해결**: `item_image_url`과 `class_name` 컬럼을 분리하여 정상 저장  

### 6. 우분투 한글 깨짐
**상황**: Azure VM Ubuntu 22.04에서 한글 파일명 깨짐 현상  
**해결**: 한국어 로캘 설정 (`ko_KR.UTF-8`) + 나눔 폰트 설치 + `~/.bashrc` 환경변수 추가  

### 7. H100 클러스터 비용 이슈
**상황**: NC96(H100×8) 클러스터 장시간 사용으로 Azure 크레딧 소진 위험 발생  
**해결**: 학습 시간 최적화 및 사용하지 않을 때 즉시 VM 중지, 필요한 데이터만 먼저 Blob Storage에 올린 후 학습 시작

## 기술적 의사결정 기록

### DB 선택: Oracle → 유지
초기 SQLite나 PostgreSQL 도입 논의도 있었으나, 학원 수업에서 익힌 Oracle을 Azure VM에 직접 설치하여 사용했습니다. `oracledb` Python 라이브러리로 연동하고 `CLOB` 타입으로 긴 텍스트 데이터를 처리했습니다.

### 이미지 모델: ResNet → YOLOv8 전환
PoC 단계에서는 단순 분류(ResNet18/50)로 검증했고, 실서비스에서는 다중 알약 탐지가 필요하여 Object Detection 모델인 YOLOv8으로 전환했습니다.

### 코드 관리: Notion → GitHub
초기 노션으로 코드를 공유했으나 코드 깨짐, 대용량 파일 처리 불가 문제로 GitHub으로 전환했습니다. 데이터 파일(2GB+)은 `.gitignore`로 제외하고 스크립트 코드만 버전 관리했습니다.

### RAG 청킹: section_type 기반 분리
허가정보를 효능/용법/주의사항/금기/부작용으로 section_type 기준으로 청킹함으로써, "이 약 임산부가 먹어도 돼?" 같은 질문에 임부금기 청크만 검색하도록 해 검색 정밀도를 높였습니다.
