# 06. AI 모델 실험 결과

## PoC 단계 — ResNet 기반 알약 이미지 분류

### 실험 개요
- **모델**: ResNet18/50 Fine-tuning (torchvision pretrained)
- **데이터**: 22종 클래스, 클래스당 약 40장, 전체 약 920장
- **분할**: Train 80% / Validation 20%
- **목적**: 데이터 증강 전략별 성능 비교

### 실험 결과

| 실험 | 증강 방식 | Accuracy | 결과 분석 |
|---|---|---|---|
| Baseline | 없음 | 1.00 | ⚠️ 소규모 샘플 과적합 의심 |
| PC1 | Light Aug (회전±10°, 밝기변화) | 1.00 | 경미한 변형은 성능에 영향 없음 |
| PC2 | Color Aug (색상·명도·채도 변화) | 0.93 | 유사 색상군 혼동 발생 |
| PC3 | Geometry Aug (원근·아핀 변환) | 0.85 | 외형 특징 훼손으로 최저 성능 |
| **PC4 ★** | **Noise Aug (센서·압축 노이즈)** | **0.94** | ✅ 실사용 환경 모사 — 가장 안정적 |
| PC5 | Rotation Aug (회전·플립·ColorJitter) | 0.93 | 촬영 각도 변화 대응 효과적 |

### 핵심 인사이트

**Geometry 증강이 최하위인 이유**  
알약 분류에서는 외형(shape)과 각인(imprint)이 핵심 특징입니다. `RandomRotation 30°`, `RandomPerspective`, `RandomAffine` 등의 강한 기하학적 변형은 이 특징 자체를 훼손하여 성능을 저하시킵니다.

**Noise 증강이 최적인 이유**  
실제 사용자가 스마트폰으로 알약을 촬영할 때 발생하는 카메라 센서 노이즈, 이미지 압축 노이즈를 모사합니다. 형태 정보를 훼손하지 않으면서 일반화 성능을 높이는 데 효과적입니다.

### 혼동 발생 클래스
Confusion Matrix 분석 결과, 다음 클래스 간 혼동이 빈번하게 발생했습니다.

## 본 학습 계획 (Azure H100)

PoC 이후 전체 5,000종 데이터로 확장 학습을 계획했습니다.

| 단계 | 시간 | 내용 |
|---|---|---|
| 1단계 | 0~6h | 데이터 전처리 + YOLO 포맷 변환 완료 |
| 2단계 | 6~30h | YOLOv8m NC80(H100×2) 탐색 학습 |
| 3단계 | 30~36h | 결과 분석 + 하이퍼파라미터 조정 |
| 4단계 | 36~68h | YOLOv8x 본격 학습 |

### 최종 모델 선택 — YOLOv8
- 여러 알약이 동시에 화면에 있을 때 각각의 위치(바운딩 박스)를 파악하는 Object Detection에 적합
- 실시간 처리 속도 우수
- ResNet은 PoC 단계의 단일 알약 분류용, YOLOv8은 실서비스 다중 알약 탐지용으로 역할 분리
