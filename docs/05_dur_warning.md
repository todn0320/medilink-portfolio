# 05. 병용금기 경고 엔진 (DUR Warning Engine)

## 개요

식약처 DUR(Drug Utilization Review) 공공데이터 130,310건을 기반으로 구현한 병용금기 경고 시스템입니다. AI 판단 없이 공식 데이터만으로 결정하는 원칙을 적용했습니다.

---

## DUR 데이터 구성

### REF_DUR_ITEM_WARNING (130,310건)
품목(약 제품) 기준 경고 데이터. 병용금기 쌍은 `MIX_ITEM_SEQ` 컬럼으로 연결됩니다.

```json
{
  "warning_type": 0,
  "type_name": "병용금기",
  "ingr_code": "D000015",
  "ingr_name_ko": "보센탄수화물",
  "item_seq": "202004778",
  "item_name": "카나보센정125밀리그램",
  "prohbt_content": "보센탄의 혈중농도 증가",
  "notification_date": "2011-06-28",
  "mixture_ingr_code": "D000279"
}
```

### REF_DUR_INGREDIENT_WARNING (3,817건)
성분 기준 경고 데이터. 특정 성분을 포함한 모든 약에 적용됩니다.

---

## 경고 유형 분류

| warning_type | 유형 | 의미 |
|---|---|---|
| 0 | 병용금기 | 두 약을 함께 복용하면 안 됨 |
| 1 | 특정연령대금기 | 특정 나이대 복용 금지 |
| 2 | 임부금기 | 임산부 복용 금지 |
| 3 | 노인주의 | 노인 복용 시 주의 필요 |
| 4 | 용량주의 | 용량 초과 주의 |
| 5 | 투여기간주의 | 투여 기간 제한 있음 |
| 6 | 효능군중복 | 동일 효능 약물 중복 복용 |
| 7 | 분할주의 | 서방정 등 분할 금지 |

---

## 병용금기 체크 API

### 양방향 체크
```
GET /drug/check?item_seq_a=A약_코드&item_seq_b=B약_코드
```

A→B, B→A 양방향 모두 조회하여 어느 방향으로든 병용금기가 존재하면 경고를 반환합니다.

### 응답 예시
```json
{
  "item_a": "타이레놀 ER 650mg",
  "item_b": "탁센 연질캡슐",
  "is_contraindicated": true,
  "warning_type": 0,
  "type_name": "병용금기",
  "prohbt_content": "동일 성분 중복 복용으로 간 독성 위험",
  "source": "식약처 DUR 품목정보"
}
```

---

## 경고 엔진 설계 원칙

1. **공식 데이터 우선**: DUR 데이터에 없는 경우 "해당 정보 없음" 반환 (AI 추측 금지)
2. **근거카드 필수**: 모든 경고에 출처(DUR 고시일, 금기 근거) 함께 제공
3. **면책 문구**: "본 정보는 의학적 진단을 대신할 수 없으며 전문가와 상담하세요" 필수 표시
4. **의료기기 아님**: 의료법 제27조 준수 — 진단·처방 기능 완전 배제

---

## 법적 고려사항

서비스 설계 단계에서 다음 법령을 검토하고 준수 방안을 설계했습니다.

- **의료법 제27조** (무면허 의료행위 금지): AI 답변이 진단·처방이 아닌 일반 정보 제공임을 명시
- **개인정보보호법 제23조**: 복약 기록은 건강에 관한 민감정보 — 별도 명시적 동의 절차 구현
- **건강기능식품법 제18조**: AI 추천 문구가 치료 효능을 암시하지 않도록 필터링
- **보건의료데이터 활용 가이드라인**: AI 학습 시 가명정보 처리 원칙 적용
