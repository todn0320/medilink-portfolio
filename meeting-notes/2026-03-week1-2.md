### 이미지 모델 선택 결정
| 모델 | 장점 | 선택 이유 |
|---|---|---|
| YOLOv8 | 실시간 다중 객체 탐지 | **최종 선택** — 여러 알약 동시 인식 |
| ViT | 높은 정확도 | 데이터 대용량 필요, 무거움 |
| EfficientNet | 속도·정확도 균형 | PoC 보조 모델로 검토 |

### 팀 규칙 확정
- 이미지 처리 라이브러리: **PIL(Pillow) 통일** (OpenCV와 BGR/RGB 혼용 방지)
- EXIF Orientation 처리: 스마트폰 가로 촬영 시 이미지 뒤집힘 방지 코드 필수
- 학습용과 평가용 코드 분리 (재현성을 위해 `set_seed` 함수 고정)

### ResNet 베이스라인 실험 결과
- **Validation Accuracy 100%** 달성
- 단, 22종 소규모 샘플 특성상 과적합 가능성 — 일반화 성능 추가 검증 필요
- 1단계 CNN 파이프라인 동작 확인 완료
