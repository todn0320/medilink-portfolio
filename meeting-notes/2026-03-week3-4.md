## 2026-03-16 | 3.4TB 이미지 데이터 수집 & 알고리즘 탐색

**참석**: 전원

### 대용량 데이터 다운로드 문제 해결

**문제**: 해외 서버(AI Hub) 3.5TB 데이터 다운로드 속도 이슈  
**검토한 방법들**:
- 학원 IP 프록시: 인터넷 속도 저하 이슈
- VPN: 3.5TB 규모 전송 속도 치명적 한계

**최종 해결 방법**: 네이버 클라우드를 프록시 서버로 구축, 국내 IP 우회하여 다운로드

### 하이브리드 비전 모델 아키텍처 결정

| 모델 | 역할 | 특징 |
|---|---|---|
| **YOLO** | Object Detection (탐지) | "한 번 보고 바로 찾기" — 속도 특화 |
| **ViT** | Classification (분류) | "이미지를 문장처럼 읽기" — 정확도 특화 |

최종 선택: **YOLOv8 단독** (속도 + 탐지 동시) + ResNet 분류 보조
